# 🚗 Ride My Way

> Application mobile Flutter de covoiturage moderne.

Ride My Way permet à des passagers et conducteurs de se connecter, organiser des trajets, et suivre leur parcours en temps réel via une interface intuitive.

---

## 🔧 Stack technique

- ⚙️ **Flutter** 3.29.3 (channel stable)
- 💻 **Dart** 3.7.2
- 📱 Ciblé pour Android & Web
- 🧩 Architecture évolutive avec modularisation
